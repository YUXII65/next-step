# AI 评测语料

> 版本：1.0  
> 用途：V1.5 Phase 3 的 AI 计划质量回归基准

## 使用方法

1. 每次修改 prompt 或 AI Context 后，从 `scripts/ai-eval-corpus.json` 中选择 10 条输入。
2. 使用当前配置的模型生成计划。
3. 按下方评分标准人工评分。
4. 记录评分结果，确认没有明显回退后再合入改动。

## 评分标准

每条用例按 1-5 分评分，1 分最差，5 分最好。

| 维度 | 说明 |
| --- | --- |
| 理解用户真实目标 | AI 是否抓住用户最想解决的问题，而不是机械生成任务 |
| 计划是否可执行 | 任务是否具体到今天能启动，不依赖外部条件 |
| 是否过度规划 | 是否避免一次性排出过多任务或过长的学习计划 |
| 是否引用真实项目上下文 | 有项目上下文时，是否使用项目名称、里程碑或停滞状态 |
| 建议是否有具体依据 | reason 是否引用真实数据，而不是“建议优先完成重要任务” |

## 当前用例

- `college-ai-plan`：大学 AI 方向规划
- `content-account`：深度内容账号启动
- `multi-goal-priority`：多个目标并行
- `english-habit`：长期学习习惯
- `freelancer-overload`：自由职业者项目过载
- `personal-site`：个人网站
- `writing-output`：写作输出
- `fitness-routine`：健身习惯
- `career-transition`：转行数据分析
- `stalled-project-restart`：停滞项目重启

## 评分建议

单条用例总分 25 分，10 条满分 250 分。建议把当前基线记录下来，之后每次改动只允许小幅波动，不允许核心维度明显回退。
