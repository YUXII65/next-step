# 走走 UI 升级风格说明

> 本文件已由 `docs/zouzou-ui-glass-morning-spec.md` 取代；正式改造请使用新文档。

## 给 Codex 的任务

请直接修改代码，把“走走”从当前偏工具感的浅灰、白色、紫色高亮界面，升级为一套“安静高级”的个人规划工具视觉。  
只改 UI 外观、布局质感和交互动效，不改变数据模型、业务逻辑、路由、AI 调用流程和核心交互方式。

## 产品定位

走走是个人 AI 规划助手，核心路径是：

1. 先倒出杂乱想法
2. AI 帮忙确认方向
3. 生成今天能推进的 1-3 件事
4. 每天晚上轻量复盘

所以视觉气质要像“一位克制、可靠、越来越懂你的私人规划教练”，而不是营销落地页、金融工具或内容社区。

- 高级感来自比例、层次和克制，不靠花哨装饰

## 当前 UI 痛点

- 背景、卡片、侧栏和表单都是同一套浅灰白，缺少质感层级
- 紫色高亮偏“后台工具”感，不够松弛高级
- 所有卡片、按钮、输入框几乎一样，页面容易显得平
- AI 相关模块没有专属但克制的视觉身份
- 大量按钮文案以“下一步：”开头，信息噪声偏大
- 桌面侧栏和移动端导航比较朴素，缺少精致的品牌感
- 动效基本只有颜色过渡，缺少轻盈的反馈

## 设计方向

整体风格命名为：**安静高级 / Quiet Premium**。

关键词：

- 安静：低噪声、少装饰、强留白
- 高级：精确的间距、克制的强调色、细腻的阴影
- 可靠：清晰的层级、稳定的状态、可预期的动效
- AI 感：只在 AI 模块使用轻量渐变、柔光和玻璃质感，不作为整页背景

一句话约束：

> 让用户打开页面后，第一眼看到“今天该推进什么”，而不是看到设计本身。

## 排版

- 继续使用现有 Inter / PingFang SC 字体栈，不新增大型字体依赖
- 标题用 600 字重，正文 400 字重，不用过粗字重制造冲击力
- 页面标题保持 20-24px，卡片标题 14-15px，辅助信息 11-12px
- 中文不要设置负字距，英文和数字可以保留现有 `font-feature-settings`
- 日期、时间、任务数等数字统一使用 `tabular-nums`
- 正文行高保持舒适，按钮文字不要换行
- 层级优先靠字号、字重、颜色和留白，不要给每段文字加背景

## 布局

- 桌面端保持左侧紧凑导航，宽度约 72px，内容区域保持居中、稳定宽度
- 移动端保留顶部品牌栏和底部主导航，但增加玻璃质感和更清晰的激活状态
- 页面大结构使用留白分块，不追求大量并排卡片
- 主面板内直接展示内容，不要出现“卡片套卡片”的多层边框
- 重要信息靠左上到右下的阅读顺序组织
- 空状态、加载状态、错误状态都要有完整视觉设计，不能只是文字

## 组件要求

### 侧栏

- 桌面图标栏使用轻微毛玻璃或半透明表面
- 当前页面使用克制的激活标识：小圆点、左侧竖条或浅色底块，任选一种并保持一致
- 图标 18-20px，悬停和激活状态对比清晰
- 移动端底部导航激活项使用主色图标，不放大、不加阴影

### 主卡片

- 基础圆角 8px，主要卡片和弹层最多 12px
- 小按钮、输入框、状态徽章保持 6-8px 圆角
- 默认使用 `1px` 浅边框加极轻阴影，不依赖厚重阴影
- 阴影建议：`0 1px 2px rgba(18, 20, 24, 0.04), 0 8px 24px rgba(18, 20, 24, 0.05)`
- 悬停只轻微提升阴影或边框，不放大、不跳动

### 按钮与输入框

- 主按钮使用主强调色，文案简短、明确，例如“让 AI 梳理”“保存复盘”
- 次按钮使用浅底、细边框和中性文字
- 危险操作只在使用场景出现，使用危险色浅底而不是大面积红块
- 输入框保持浅灰底，聚焦时白色底、主色边框和柔和焦点环
- 不要给所有按钮加图标，只有需要解释动作时使用图标

### 状态与标签

- 状态徽章使用 8-12% 透明度的同色浅底、同色文字和 1px 同色细环
- 成功、警告、危险色只用于真实状态，不做大面积装饰
- 完成状态使用轻盈的勾选反馈，不用加粗色块

### AI 模块

- AI 助手、AI 生成、AI 建议使用统一但克制的视觉身份
- 图标可以使用冷青色渐变或柔光，不要整页渐变色
- AI 卡片可以比普通卡片多一点层次，例如浅色边框、左上角微光、更细腻的阴影
- 生成中状态使用轻柔呼吸或转圈，不用闪烁、弹跳或夸张动画

### 表单与编辑器

- 项目、任务、复盘表单保持一致的字段间距和标签样式
- 编辑状态与只读状态要有明确区别：只读更轻，编辑更明显
- 折叠面板的展开与收起保持平滑

### 空状态

- 空状态图标使用中性浅底圆角方块
- 文案简洁，只给一个可执行建议
- 可以增加一条淡色引导线或图形，但不要使用卡通插画

## 动效

- 悬停、点击等微交互使用 120-180ms，`ease-out`
- 面板展开、抽屉、页面过渡使用 240-320ms
- 按压反馈可以轻微缩放到 `0.98`
- 所有动效必须支持 `prefers-reduced-motion`
- 不使用弹跳、旋转、长闪烁、整页动画等装饰效果

## 暗色模式

- 浅色和深色不是简单反色，深色应比浅色更收敛
- 深色卡片和背景之间保留清晰但柔和的边界
- 阴影可以更深，但不能产生明显发光
- 玻璃质感在深色下使用半透明深灰，而不是高亮玻璃
- 主强调色在深色下提亮，保证按钮和焦点可见

## 不要做

- 不要做整页渐变、霓虹色、大面积紫色或蓝色背景
- 不要做营销式 Hero、超大标题和产品介绍式首页
- 不要到处使用毛玻璃
- 不要加入新的插画、贴纸、emoji 或 3D 装饰
- 不要为了高级感牺牲信息密度和操作效率
- 不要保留“下一步：”这类重复按钮前缀，除非某处它确实是产品语义
- 不要修改页面结构和数据逻辑

## 验收标准

- 浅色和深色模式都清晰、可读、不刺眼
- 375px 移动端和 1280px 桌面端都没有文字溢出或元素重叠
- 主要页面都有完整空状态、加载状态、交互反馈
- 侧栏、按钮、输入框、状态徽章、卡片层级有统一设计语言
- AI 模块有克制的专属视觉，不与普通功能模块混同
- 不改数据模型、路由、AI 调用和核心交互逻辑
- `pnpm lint` 和 `pnpm build` 通过
