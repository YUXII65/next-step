# 走走 UI 改造规范：晨光玻璃（Glass Morning）

## 给 Codex 的任务

请按本文件把“走走”改造为以 **晨光玻璃 / Glass Morning** 为主视觉的版本。  
浅色模式以晨光玻璃为基准；暗色模式参考深空石墨的结构、层次和克制光感，但必须与晨光玻璃同源，不能保留深空石墨作为独立风格的个体特征。

只改 UI 外观、布局质感、组件状态和动效。  
不改变数据模型、业务逻辑、路由、AI 调用流程和核心交互方式。

## 产品定位

走走是个人 AI 规划助手，核心路径是：

1. 倒出杂乱想法
2. AI 确认方向
3. 生成今天能推进的 1-3 件事
4. 每天晚上轻量复盘

视觉气质要像“清晨里一个清爽、可靠、越来越懂你的私人规划教练”，不是金融工具、营销落地页或内容社区。

## 参考图

浅色模式主参考：

`docs/zouzou-ui-references/glass-morning-light.png`

暗色模式结构参考：

`docs/zouzou-ui-references/night-focus-paired-dark.png`

暗色模式只借鉴以下内容：

- 深色石墨表面的分层方式
- 卡片与背景之间的层次
- 克制的光晕和夜间阴影
- 大数字、状态标签、信息卡的清晰对比

暗色模式不要保留以下内容：

- 琥珀色作为主强调色
- 深空石墨的“独立个人风格”
- 与晨光玻璃不同的品牌色体系

## 设计原则

- 主色系统始终是：钴蓝 + 青色 + 玻璃白
- 页面保持空气感，但不空
- AI 模块可以有专属轻光感，但不能喧宾夺主
- 浅色和深色使用同一套结构、同一套强调色语义
- 高级感来自玻璃层次、柔和阴影、精确间距和克制的渐变
- 不要为了风格化牺牲信息密度和操作效率

## 全局样式

### 背景

- 浅色使用柔和低对比渐变，不能像霓虹或彩色玻璃
- 深色使用更深的蓝灰渐变，保持与浅色同构
- 页面背景不要出现大块高饱和色

### 字体

- 继续使用现有 Inter / PingFang SC 字体栈
- 标题 600 字重，正文 400 字重
- 页面标题 24-30px，卡片标题 15-18px，辅助信息 11-12px
- 中文不设置负字距，英文和数字保留现有 `font-feature-settings`
- 日期、时间、任务数、进度统一使用 `tabular-nums`
- 不使用超大标题、不需要新增字体依赖

### 圆角

- 主卡片：18-24px
- 玻璃卡片：18-24px
- 小按钮、输入框、状态徽章：10-13px
- 胶囊只用于状态、进度、标签

### 阴影

- 卡片使用蓝色调轻阴影，不依赖粗黑边框
- 深色下阴影更深，但不产生明显发光
- 浮动层、弹层、命令面板可以使用更柔和的浮起阴影

## 页面与组件改造

### 侧栏与导航

- 桌面左侧栏保持紧凑，宽度约 72px
- 侧栏使用玻璃表面和轻微 `backdrop-filter`
- 当前页面使用“浅蓝底 + 钴蓝图标”的激活状态
- 移动端顶部品牌栏和底部导航使用相同玻璃语言
- 图标统一 18-20px，激活项不放大、不加跳动

### 今日页

- 顶部问候区和日期保持清爽
- “今日重点”卡片使用玻璃表面、大圆角、柔和阴影
- 重点卡片内可以加入圆形进度或细进度条
- 主任务标题 24-30px，信息使用小标签呈现
- AI 判断卡片使用青色小光点和浅蓝/浅青底，不放整页渐变
- 快速记录卡片使用玻璃表面，输入框保持浅蓝灰底
- 底部统计卡片使用 3 等分布局，数字保持大而安静

### 书桌页

- 项目列表使用玻璃面板
- 当前项目使用钴蓝浅底和高亮文字
- 新建项目使用浅色虚线按钮，不抢主任务
- 项目目标、当前里程碑使用浅蓝灰块
- 任务列表使用透明或轻玻璃行，不使用多层卡片套嵌
- 完成状态使用柔和的绿色轻底

### 复盘页

- 历史复盘列表使用玻璃侧栏
- 当前日期使用钴蓝浅底
- 当日总结和明日第一步使用轻玻璃编辑卡
- 本周统计使用 3 个轻卡片，不使用强色块

### 工具匣页

- 现状速览使用 4 个轻玻璃统计卡
- 推荐工具使用统一模块卡
- 可用 / 暂不开放使用状态徽章表达
- 专注计时等工具保持同一种卡片语言

### 引导、登录和落地页

- 首次引导、注册、登录、落地页使用与主应用一致的玻璃语言
- 不额外引入营销式 Hero 风格
- 演示流程保留现有功能和文案，只改视觉

### 通用组件

- 主按钮：钴蓝底、白色文字、10-13px 圆角、柔和阴影
- 次按钮：玻璃白底、浅蓝边框、次要文字
- 输入框：浅蓝灰底，聚焦后白色底 + 钴蓝边框 + 柔和焦点环
- 状态徽章：8-12% 透明度的同色浅底 + 同色文字 + 同色细环
- 空状态：中性玻璃卡，图标浅底，文案只给一个可执行建议
- AI 生成中：使用轻柔呼吸或转圈，不使用闪烁和弹跳

## 动效

- 悬停、点击等微交互使用 120-180ms，`ease-out`
- 面板展开、抽屉、命令面板使用 240-320ms
- 按压反馈可轻微缩放到 `0.98`
- 所有动效支持 `prefers-reduced-motion`
- 不使用弹跳、旋转、长闪烁、整页动画等装饰效果

## 暗色模式规则

- 暗色模式必须看起来是“晨光玻璃的夜间版本”，不是另一套产品
- 主强调色仍是钴蓝，AI 仍是青色
- 琥珀色只作为警告语义，不作为主视觉
- 玻璃表面使用深蓝灰半透明，不使用高亮玻璃
- 卡片和背景之间保留清晰但柔和的边界
- 阴影更深，但不产生明显发光

## 不要做

- 不要整页霓虹渐变
- 不要保留深空石墨的琥珀主色和个人化特征
- 不要到处叠加毛玻璃
- 不要加入新的插画、贴纸、emoji 或 3D 装饰
- 不要为了风格化牺牲信息密度和操作效率
- 不要改变页面结构和数据逻辑
